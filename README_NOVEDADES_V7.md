# PMO Bot SIGRED V7 — fuentes ampliadas

Mejoras: dos informes DOCX originales, nueva base de conocimiento con hechos y escenarios claramente separados; figuras extraídas de los informes; tarjetas rediseñadas; docente y equipo visible; trazabilidad de resultados; conservación de 1280 consultas locales V6.

## Ejecución
- Node.js >=20.6
- En raíz: `npm start` (modo documental) o `npm run dev` con `backend/.env` privado para Gemini.
- Abrir http://localhost:8787
- Ejecutar pruebas: `npm test`
- En GitHub subir los archivos descomprimidos; nunca `.env`.
- Publicación estática: carpeta `sitio`; backend independiente para Gemini.

## Límite esencial
El sistema es un prototipo académico y NO demuestra aprobación institucional, operación en producción o beneficios ya realizados. No se simulan resultados reales.
